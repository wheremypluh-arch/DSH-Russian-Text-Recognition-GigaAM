# dsh-voice-ru

Русский голосовой ввод для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) одним бандлом:
локальное распознавание **GigaAM v3** на CPU, оффлайн, без API-ключей. Кнопка микрофона в композере,
горячие клавиши и голосовая активация по фразе — с пунктуацией и цифрами.

Актуально для версии **1.8.0**. Проверено на DSH `0.2.2-rc.1`, Node.js 24, Windows x64.

## Быстрый старт

1. Установите бандл и перезапустите DSH — модель (~320 МБ) скачается при первом обращении.
2. `Ctrl+Shift+L` — включить прослушивание. В правом нижнем углу появится зелёная подсказка.
3. Скажите **«Эй, Гига»** — раздастся сигнал, лампа станет синей: диктуйте. После паузы 5 секунд
   текст появится в поле ввода; отправьте `Enter` или скажите **«Отправить»**.

Клавиши работают, когда окно DSH в фокусе. Всё распознавание — локально, аудио никуда не уходит.

## Команды

### Клавиатура

Все команды переназначаются в **Настройки → Горячие клавиши** (документ `dsh.keybindings.v1`).

| Команда | Что делает | web | desktop |
| --- | --- | --- | --- |
| `voice.dictateHold` | push-to-talk: держите клавиши, говорите, отпустите — текст в поле ввода | `Ctrl+Shift+V` | `F9` |
| `voice.dictateToggle` | нажали — запись пошла; нажали ещё раз — текст в поле ввода | `Ctrl+Shift+.` | `F10` |
| `voice.listen` | включить/выключить прослушивание фразы-триггера | `Ctrl+Shift+L` | `F8` |

`Esc` во время записи отменяет её; повторный `Ctrl+Shift+L` (или `Esc`) выключает прослушивание.

### Голос

| Сказать | Что произойдёт |
| --- | --- |
| **«Эй, Гига»** | включает диктовку: сигнал, синяя лампа «Слушаю очень внимательно…» |
| **«Отправить»** / «отправь» / «готово» | отправляет содержимое поля ввода сообщением |
| **«стоп»** / «отмена» / «отмени» | выбрасывает надиктованное, режим остаётся включён |
| **«Эй, Гига, купи хлеб»** | команда и текст одной фразой — «купи хлеб» уйдёт сразу |

Фраза сравнивается по **слитной** форме: «Эй, Гига», «Эйгига», «эй гига!» — одно и то же.
Допускается одна ошибка распознавания (`wakeTolerance`) и слово-филлер перед фразой
(«ну, эй гига, …»). Регистр, пунктуация и удвоенные буквы не важны.

### Индикатор

Пока режим включён, в правом нижнем углу висит «лампочка»:

| Цвет | Текст | Когда |
| --- | --- | --- |
| зелёный | `Скажите: «Эй Гига!»` | прослушивание включено |
| синий | `Слушаю очень внимательно…` | фраза распознана, идёт диктовка |
| красный | `запись` | идёт запись (hold/toggle) |
| жёлтый | `распознаю` | сегмент отправлен в модель |

Рядом с подписью — пять полосок уровня микрофона: они показывают, слышит ли вас браузер,
ещё до первой фразы. При включении прослушивания плагин сразу прогревает выбранную модель
(`prepare`), поэтому первый распознанный сегмент не ждёт загрузку.

## Что внутри

Пакет — bundle-бандл: своего кода распознавания он не содержит, только компонует профиль DSH
(`cordis.patch.yml`) и добавляет клиентскую половину (`lib/client.js`). Движок — пакет
[`dsh-gigaam-stt`](https://www.npmjs.com/package/dsh-gigaam-stt) (GigaAM v3 `e2e_ctc` int8
через `sherpa-onnx`, который идёт в комплекте с DSH).

| id строки | что даёт |
| --- | --- |
| `speech-to-text` | сервис распознавания: `defaultProvider: gigaam-local`, `language: ru` |
| `speech-to-text-gigaam` | локальный провайдер, модель в `$DSH_HOME/speech-to-text/gigaam` |
| `api-speech-to-text` | Remote для браузера, лимит записи 600 с / 20 МиБ (штатные 120 с / 4 МиБ) |
| `ui-voice-input` | кнопка микрофона в композере |
| `voice-hotkeys` | клиентская часть: горячие клавиши, голосовая активация, индикатор |

## Установка

**Не включайте одновременно официальный `@deepseek-ai/dsh-experimental-voice-input-bundle`.**
Оба бандла вставляют строку с id `speech-to-text`, композиция упадёт на дубликате id.

Из git-репозитория (профиль по умолчанию — `web`):

```bash
dsh plugin --profile web add github:wheremypluh-arch/DSH-Russian-Text-Recognition-GigaAM
```

Или в Web UI: **Plugins** → поле установки → `github:wheremypluh-arch/DSH-Russian-Text-Recognition-GigaAM`.

### Если хочется только горячие клавиши

Клиентскую половину можно смонтировать отдельно, не заменяя официальный голосовой ввод: пакет
ставится как `link:`-зависимость, а в `profiles/<профиль>/cordis.patch.yml` добавляется строка:

```yaml
- insert:
    - id: voice-hotkeys
      name: dsh-voice-ru
      config:
        wakePhrases: ['эй гига']
        sendDelayMs: 5000
```

Запись обязана быть внутри `insert:` — оверрайд по id для новой строки молча отбрасывается.

### Поиск в DSH Discover

В репозитории лежит [index.json](index.json) — индекс формата 1 для Discover:

```
https://raw.githubusercontent.com/wheremypluh-arch/DSH-Russian-Text-Recognition-GigaAM/main/index.json
```

## Требования

- DSH `>=0.2.2-rc.1` (профиль с `nodeLinker: hoisted` — штатный дефолт) и Node.js 22+;
- npm registry (зависимость `dsh-gigaam-stt`) и `huggingface.co` либо `hf-mirror.com` (модель);
- ~350 МБ на диске, ~520 МБ RAM во время распознавания;
- разрешение браузера на микрофон для origin DSH Web.

Модель скачивается при первом обращении, проверяется по SHA-256 и выгружается после 5 минут простоя.

## Настройка

### Движок распознавания

Строка `speech-to-text-gigaam` в `$DSH_HOME/profiles/web/cordis.patch.yml`:

```yaml
- id: speech-to-text-gigaam
  config:
    threads: 2
    maxSegmentSeconds: 20
    numbers: words
```

Полный список — в README пакета `dsh-gigaam-stt`.

### Голосовая часть

Строка `voice-hotkeys`:

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `wakePhrases` | `['эй гига']` | фразы активации (сравниваются по слитной форме) |
| `sendPhrases` | `['отправь', 'отправить', 'готово']` | слова, отправляющие текст |
| `cancelPhrases` | `['стоп', 'отмена', 'отмени']` | слова, выбрасывающие надиктованное |
| `sendDelayMs` | `5000` | пауза тишины, после которой фраза закрывается сама |
| `delivery` | `draft` | `draft` — текст в поле ввода; `send` — сразу сообщением |
| `wakeTolerance` | `1` | допуск опечаток распознавания (0–3) |
| `fillerWords` | `['ну','так','а','и','вот','окей','ок']` | что можно сказать перед фразой |
| `beep` | `true` | короткий сигнал при активации и отправке |
| `debug` | `false` | писать в консоль, что услышала модель |

## Ограничения

- Потокового ASR в стеке нет: фраза распознаётся после паузы, задержка ~0.1–0.2 с на фразу.
- Микрофон занят, пока включён режим; в фоновой вкладке браузер может душить таймеры.
- В web горячая клавиша обязана содержать модификатор; `Ctrl+Shift+V` забирает у композера
  «вставить без форматирования» — при необходимости переназначьте команду.
- На Linux большинство `Ctrl+Shift+…` зарезервировано клиентом — назначьте доступную комбинацию.
